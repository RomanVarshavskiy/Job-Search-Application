# Job Search Application

Приложение для поиска вакансий с использованием API HeadHunter и сохранением данных в PostgreSQL.

## Описание

Это консольное приложение позволяет получать информацию о вакансиях и работодателях с HeadHunter, сохранять их в базу данных PostgreSQL и выполнять различные запросы к сохраненным данным.

## Функциональность

- Получение данных о работодателях через API HeadHunter
- Получение данных о вакансиях через API HeadHunter
- Сохранение данных в PostgreSQL
- Возможность выполнять следующие запросы к базе данных:
  - Получение списка всех компаний и количества их вакансий
  - Получение списка всех вакансий с детальной информацией
  - Получение средней зарплаты по вакансиям
  - Получение вакансий с зарплатой выше средней
  - Поиск вакансий по ключевому слову

## Требования

- Python 3.13+
- PostgreSQL 12+
- Poetry

## Использование

1. Активируйте виртуальное окружение Poetry:
poetry shell

2. Запустите приложение:
python main.py

3. Следуйте инструкциям в консольном меню для выполнения различных операций.
